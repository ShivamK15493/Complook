<h1>PROJECT DESCRIPTION</h1>
Complook is a lightweight web application built using HTML, CSS,
and JavaScript that allows users to search for companies and instantly view their
key details.All company data is stored locally in JSON format, making the project
fast, simple, and independent of external APIs.

This project is ideal for learning JavaScript data handling, JSON parsing, and search-based UI interactions.

<h2>Features</h2>
<ul>
  <li>Search companies by name</li>
  <li>Displays company information</li>
  <li>Fast and responsive interface</li>
  <li>Beginner-friendly and easy to extend</li>
</ul>

<h2>Technologies Used</h2>
<ol>
  <li>HTML – Structure of the web application</li>
  <li>CSS – Styling and layout</li>
  <li>JavaScript – Logic, search functionality, and data handling</li>
  <li>JSON – Local storage of company data</li>
</ol>

<h2>Use Cases</h2>
<ul>
  <li>Learning JSON handling in JavaScript</li>
  <li>Practicing search functionality</li>
  <li>Building data-driven front-end projects</li>
  <li>Academic or portfolio projects</li>
</ul>
